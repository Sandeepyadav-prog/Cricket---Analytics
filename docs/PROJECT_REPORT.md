# Cricket Performance & Analytics
## Project Documentation

### 1. Introduction
This project focuses on analyzing IPL cricket data using Big Data technologies and Business Intelligence tools.

### 2. Problem Statement
Cricket generates large volumes of match and ball-by-ball data. An organized analytical platform is required to process this data and identify meaningful patterns in player, team, season, and venue performance.

### 3. Objectives
- Extract IPL cricket data using Python.
- Process data using Apache Spark and Databricks.
- Implement Bronze, Silver, and Gold data layers.
- Generate analytical datasets.
- Develop interactive Power BI dashboards.

### 4. Dataset
Source: Cricsheet (https://cricsheet.org/)

The project uses IPL ball-by-ball JSON data and match information.

### 5. Technologies Used
- Python
- Apache Spark
- PySpark
- Databricks
- Delta Lake
- Microsoft Power BI
- GitHub

### 6. Implementation
The project is implemented in three data-processing layers:

**Bronze:** Raw data ingestion.

**Silver:** Data cleaning and validation.

**Gold:** Analytical aggregations for batting, bowling, teams, and venues.

### 7. Dashboard Modules
1. Season Overview
2. Batting Analytics
3. Bowling Analytics
4. Team & Venue Analytics

### 8. Results
The project generates six Gold-layer analytical datasets and presents the results through four interactive Power BI dashboard pages.

### 9. Conclusion
The project demonstrates an end-to-end Big Data Analytics workflow, from raw data extraction to interactive business intelligence reporting.

### 10. Future Scope
- Real-time cricket analytics.
- Machine learning-based performance prediction.
- Additional cricket data integration.
- Automated pipeline scheduling.
